The marker has not started

If the tutorial menu and group list on the left are empty, this file is being shown in a preview (Outlook, Teams, OneDrive, SharePoint, Gmail or Google Drive), and previews do not run the app.

  1. Download the file to your computer (for example to Documents).
  2. Find it in Finder or File Explorer, right-click it, choose Open With, then Google Chrome or Microsoft Edge.
  3. The address bar should start with file://. Bookmark it so you reopen the same copy each time, because your marks are saved with that copy in that browser.
